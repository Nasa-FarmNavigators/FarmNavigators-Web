🌍 Farm Navigators Angola
📌 O que é a plataforma?

O Farm Navigators Angola é uma plataforma digital (Mobile + Web) que utiliza dados climáticos e de solo da NASA, inteligência artificial e geolocalização para ajudar agricultores angolanos a tomar melhores decisões de plantio, melhorar a produtividade e conservar o meio ambiente.

A plataforma conecta agricultores, técnicos agrícolas, ONGs e governo em um ecossistema colaborativo de agricultura inteligente e sustentável.
📱 O que ela fará?
👨‍🌾 Para Agricultores (Mobile App)

    Mostrar previsões climáticas locais (chuva, temperatura, umidade do solo).
    Exibir o estado de conservação da área/localização (qualidade do solo, risco de erosão, degradação, queimadas).
    Enviar alertas de pragas e doenças baseados em dados satelitais.
    Recomendação personalizada de culturas a plantar (Farm Tinder 🌱❤️) cruzando solo, clima e histórico.
    Ensinar boas práticas agrícolas com mini-vídeos curtos (AgriFlix).
    Simulador de Crescimento → agricultor vê a evolução de uma cultura baseada nas condições reais da sua terra.
    Funcionar mesmo sem internet, via USSD/SMS (previsões básicas e alertas).
    Suporte em idiomas nacionais (Kimbundu, Umbundu, Kikongo).

🏛️ Para ONGs, Governo e Técnicos (Web Platform)

    Acompanhar dados agrícolas por região em mapas interativos (Mapbox).
    Visualizar estado de conservação do solo e cobertura vegetal em cada província.
    Gerar relatórios de produtividade e riscos climáticos.
    Subir e gerir conteúdos educativos (vídeos, artigos).
    Usar dados para apoiar políticas públicas agrícolas e ambientais.

🌍 Qual o impacto no povo angolano?

    Mais Produção, Mais Renda → agricultores saberão o que plantar, quando plantar e como cuidar → menos perdas, mais rendimento.
    Inclusão Digital Rural → acesso por telemóveis simples (USSD), levando tecnologia até zonas sem internet.
    Educação Acessível → mini-aulas curtas e simples, em português e línguas locais.
    Sustentabilidade → monitoramento da conservação da terra e combate à degradação do solo.
    Redução da Fome → uso de dados para aumentar segurança alimentar.
    Planejamento Estratégico → ONGs e governo terão dados confiáveis para orientar projetos agrícolas.

✅ O que será possível fazer com a plataforma?

    Um agricultor em Benguela poderá ver que plantar batata em outubro aumenta o rendimento em 25%.
    Um agricultor no Huambo sem internet receberá via USSD a previsão de chuva e alertas de pragas.
    Um produtor poderá verificar o estado de conservação do solo da sua fazenda e saber como melhorar.
    Uma ONG em Luanda verá num mapa interativo quais províncias têm maior risco de seca.
    O governo usará dados para subsídios agrícolas e combate à fome.
    Jovens agricultores aprenderão técnicas novas com vídeos rápidos (AgriFlix) e um simulador de sementes.

📚 Farm Navigators - Documentação das Rotas API

Este documento descreve todas as rotas disponíveis no Farm Navigators Data Service, sua funcionalidade, parâmetros e como elas se integram no ecossistema do projeto.
🏗️ Arquitetura do Sistema

O Farm Navigators Data Service é um microserviço Python/FastAPI responsável por:

    Integração com APIs da NASA (AppEEARS, GLAM, Giovanni, Crop-CASMA)
    Processamento de dados geoespaciais (NDVI, EVI, umidade do solo)
    Análise de Machine Learning para recomendações
    Geração de alertas baseados em dados satelitais
    Sincronização com o banco NeonDB compartilhado com Node.js

Fluxo de Dados

Mobile/Web → Node.js API → Python Data Service → NASA APIs
                ↓                    ↓
            NeonDB ←←←←←←←←←←←←←←← Dados Processados

🔗 Estrutura Base da API

Base URL: http://localhost:8000 Documentação Interativa: http://localhost:8000/docs

Todas as rotas seguem padrões REST com códigos de status HTTP apropriados.
📋 Rotas Disponíveis
🏥 1. Health Check (/health)

Rotas para verificar o status do serviço e conectividade.
GET /health/

Propósito: Verificação básica de saúde do serviço
Uso: Monitoramento, load balancers, CI/CD
Parâmetros: Nenhum

Resposta:

{
  "status": "healthy",
  "service": "Farm Navigators Data Service",
  "environment": "development"
}

GET /health/db

Propósito: Verifica conectividade com o banco NeonDB
Uso: Diagnóstico de problemas de conexão
Parâmetros: Nenhum

Resposta (Sucesso):

{
  "status": "healthy",
  "database": "connected",
  "test_query": "success"
}

Resposta (Erro):

{
  "detail": "Database connection failed: [erro específico]"
}

Como usar no projeto:

    Node.js chama antes de fazer requests para verificar se Python service está ativo
    Monitoramento verifica saúde dos serviços
    CI/CD valida deployment

🛰️ 2. Dados NASA (/nasa)

Rotas para buscar e processar dados satelitais e meteorológicos da NASA.
GET /nasa/satellite/ndvi

Propósito: Busca dados de NDVI (Normalized Difference Vegetation Index) para análise de vegetação
Uso: Monitorar saúde das culturas, detectar estresse hídrico

Parâmetros:

    latitude (float): Coordenada geográfica (-90 a 90)
    longitude (float): Coordenada geográfica (-180 a 180)
    start_date (date): Data inicial no formato YYYY-MM-DD
    end_date (date): Data final no formato YYYY-MM-DD

Exemplo de requisição:

GET /nasa/satellite/ndvi?latitude=-8.8390&longitude=13.2894&start_date=2025-09-01&end_date=2025-09-30

Resposta:

{
  "data": [
    {
      "date": "2025-09-15",
      "ndvi": 0.75,
      "source": "MODIS",
      "quality": "good"
    }
  ],
  "metadata": {
    "total_observations": 15,
    "cloud_coverage_avg": 12.5
  }
}

Como usar no projeto:

    Farm Tinder: Avaliar saúde atual das culturas para recomendações
    Alertas: Detectar declínio da vegetação (seca, pragas)
    Dashboard Web: Gráficos de evolução temporal

GET /nasa/weather

Propósito: Busca dados meteorológicos (chuva, temperatura, umidade)
Uso: Previsões, planejamento de irrigação, alertas climáticos

Parâmetros: Mesmos do NDVI

Resposta:

{
  "data": [
    {
      "date": "2025-09-15",
      "precipitation_mm": 5.2,
      "temperature_c": 28.5,
      "humidity": 65.8,
      "wind_speed_mps": 3.1
    }
  ]
}

Como usar no projeto:

    Simulador de Crescimento: Input para modelagem
    Alertas: Detectar ondas de calor, secas
    Recomendações: Timing ideal para plantio

GET /nasa/soil-moisture

Propósito: Dados de umidade do solo via Crop-CASMA
Uso: Otimização de irrigação, detecção de estresse hídrico

Resposta:

{
  "data": [
    {
      "date": "2025-09-15",
      "soil_moisture": 0.35,
      "depth_cm": 10,
      "source": "SMAP"
    }
  ]
}

POST /nasa/sync/farm/{farm_id}

Propósito: Sincronização automática de todos os dados NASA para uma fazenda
Uso: Cron jobs, atualizações em lote

Parâmetros:

    farm_id (int): ID da fazenda no banco
    days_back (query, opcional): Dias históricos para buscar (padrão: 30)

Resposta:

{
  "message": "Dados sincronizados com sucesso",
  "farm_id": 123,
  "records_created": 45
}

Como usar no projeto:

    Cron Job: Execução diária para atualizar dados
    Node.js: Trigger quando agricultor adiciona nova fazenda
    Onboarding: População inicial de dados históricos

🚨 4. Alertas (/alerts)

Sistema de alertas automáticos baseados em dados satelitais e meteorológicos.
GET /alerts/active/{farm_id}

Propósito: Busca alertas ativos para uma fazenda
Uso: Notificações push, dashboard principal

Resposta:

[
  {
    "id": 789,
    "farm_id": 123,
    "alert_type": "drought",
    "severity": "high",
    "title": "Risco de Seca Detectado",
    "message": "Dados de satélite indicam umidade do solo abaixo de 20% nos últimos 7 dias. Recomenda-se irrigação imediata.",
    "source": "SMAP_SoilMoisture",
    "created_at": "2025-10-02T10:30:00Z",
    "expires_at": "2025-10-09T10:30:00Z"
  }
]

GET /alerts/all/{farm_id}

Propósito: Histórico completo de alertas com filtros
Uso: Análise histórica, relatórios

Parâmetros de Query:

    limit: Número máximo de alertas (padrão: 50)
    alert_type: Filtro por tipo (drought, flood, pest, etc.)
    severity: Filtro por severidade (low, medium, high, critical)

POST /alerts/acknowledge/{alert_id}

Propósito: Marcar alerta como visto/tratado pelo agricultor
Uso: Gestão de notificações, analytics
POST /alerts/generate/{farm_id}

Propósito: Gerar alertas automáticos baseados nos dados NASA mais recentes
Uso: Trigger manual, troubleshooting
POST /alerts/bulk-generate

Propósito: Geração em massa para todas as fazendas
Uso: Cron job noturno, processamento em lote

Como usar no projeto:

    Push Notifications: Node.js consome alertas ativos e envia para mobile
    Dashboard: Widgets de alertas críticos
    Email/SMS: Integração para alertas de alta severidade
    Analytics: Métricas de resposta a alertas

🔄 Fluxos de Integração
1. Onboarding de Nova Fazenda

1. Agricultor cadastra fazenda no Mobile/Web
2. Node.js salva dados básicos no NeonDB
3. Node.js chama POST /nasa/sync/farm/{farm_id} 
4. Python busca dados históricos da NASA
5. Python gera primeiras recomendações
6. Sistema está pronto para uso

2. Recomendação Diária (Farm Tinder)

1. Agricultor abre app
2. Mobile chama Node.js
3. Node.js chama POST /recommendations/farm-tinder/{farm_id}
4. Python analisa dados NASA + ML
5. Retorna lista rankeada de culturas
6. Mobile exibe interface tipo Tinder

3. Sistema de Alertas Automático

1. Cron job executa POST /alerts/bulk-generate (diário)
2. Python analisa dados NASA recentes
3. Detecta anomalias (seca, pragas, etc.)
4. Gera alertas no banco
5. Node.js consome alertas via GET /alerts/active/{farm_id}
6. Node.js envia push notifications
